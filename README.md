## 📌 Acerca del Proyecto
Este repositorio contiene un material infográfico claro, directo y con rigor técnico diseñado para entender de forma rápida y visual las **Bases de Datos NoSQL**. 

Ideal para repasar los conceptos clave, conocer los modelos de almacenamiento y saber cuándo utilizar un sistema no relacional frente a las bases de datos SQL tradicionales.

---

## 🚀 Contenido de la Infografía
La guía aborda los siguientes puntos esenciales:
* **¿Qué es NoSQL?:** Definición, concepto de *Not Only SQL* y flexibilidad de esquemas.
* **Los 4 Modelos Principales:** 
  * Clave-Valor *(Redis, DynamoDB)*
  * Documentales *(MongoDB)*
  * Familias de Columnas *(Cassandra)*
  * De Grafos *(Neo4j)*
* **Características Clave:** Escalabilidad horizontal, rendimiento y la filosofía *BASE*.
* **Guía de Decisión:** Cuándo elegir SQL vs. Cuándo elegir NoSQL.
